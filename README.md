# Health Log（PWA試作版）

## 内容
- 身体データ（体重・体脂肪率・筋肉量・安静時心拍数）
- 運動・歩数
- 食事・PFC
- 睡眠・水分・体調
- 体重グラフ
- JSONバックアップ／復元
- ホーム画面追加・オフライン用キャッシュ

## 重要な制限
- 記録はブラウザの localStorage に保存されます。Safariのデータ削除や端末変更で失われる可能性があるため、分析画面から定期的にJSONバックアップを保存してください。
- iPhone/iPad間の自動同期はありません。
- このWeb版はApple HealthKitへ直接アクセスできません。
- HealthKit連携にはネイティブiOSアプリ化、HealthKit capability、権限説明、ユーザーの許可が必要です。

## 公開方法
このフォルダの中身をHTTPS対応の静的ホスティングへアップロードしてください。例：GitHub Pages等。
公開されたURLをiPhone/iPadのSafariで開き、「共有」→「ホーム画面に追加」→「Webアプリとして開く」を有効にして追加します。

## データの扱い
健康情報は機微な個人情報です。公開URLを第三者に共有せず、認証なしの公開サービスへ実データを置かないでください。現試作版は端末内保存のみです。
